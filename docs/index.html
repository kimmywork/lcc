LCC

Layered Chromatic Code · 方形分层彩色码

L1/L2/L3a/L3b 共用同一套方形几何；可逆亮度约束、真 RS 纠错、BCH 格式带。 摄像头/屏幕反光场景建议使用 L1 黑白 + constraint: off；多级灰/彩在强反光下会丢灰阶。
