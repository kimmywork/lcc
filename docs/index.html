LCC

Layered Chromatic Code · 方形分层彩色码

L1 / L2a / L3b / L3c / L1s / L2s / L3s / L3t 共用同一套方形几何；形状层用 8 种线形态把容量从 1 bit 扩到 7 bit/模块。 摄像头/屏幕反光场景建议使用 L1 / L2a / L3b / L3c / L3s + constraint: off；形状层最低建议 16px，模块尺寸 Auto 会优先选更大的方块。

生成码面

摄像头首选 L1 / L2a / L3b / L3c / L3s；L2b/L3d 需受控，L3t 可用 N≥25，模块最低建议 16px，Auto 会优先选更大方块；L4e/L4f 仅清洁/数字/打印。
