# 2026-11-10

## 22:41:05 CST

定位标记改为分通道黑白场，用来在分类前去掉中性色偏。多帧合成和扫描解码放进 `native/` 的 C 核心，编成 `docs/lib/lcc.wasm` 给网页优先调用；JS 仍是对照，constraint 码和 WASM 失败时回退 JS。

原因：色偏不能靠多帧平均修，合成和解码又都太慢。验证是 `npm test` 21 项通过，合成像素差不超过 1，同一夹具上 WASM 比 JS 快。

缺口：这台机器的 Emscripten 包没下完，当前 wasm 由 zig 的 wasm32-wasi 目标编出；`npm run build:wasm` 在有 `emcc` 时改走 Emscripten。C 解码还没做 constraint / Viterbi。

## 23:17:59 CST
